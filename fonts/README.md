# Font logo BookStory

Các file WOFF2 được lưu cùng website để logo không phụ thuộc font có sẵn trên máy hoặc Google Fonts khi chạy.

| File | Nguồn | Phiên bản | Phạm vi |
| --- | --- | --- | --- |
| `kaushan-script-latin.woff2` | `@fontsource/kaushan-script` | 5.3.0 | Latin, normal, 400 |
| `russo-one-latin.woff2` | `@fontsource/russo-one` | 5.3.0 | Latin, normal, 400 |

Được khai báo trong `css/components/header.css` và dùng bởi logo trong `components/header.php`. Không đổi tên font trong các file.

Font sử dụng SIL Open Font License 1.1. Giữ các giấy phép `kaushan-script-OFL.txt` và `russo-one-OFL.txt` cùng các font khi phân phối.
